# UI Guidelines

Use:

- Sidebar layout
- Sticky page headers
- Card sections
- Spacious tables

---

# Components

Use:

- Rounded corners
- Soft shadows
- Thin borders
- Clean typography

---

# Colors

- Neutral base colors
- Soft grays
- White backgrounds
- Meta-inspired blue accents

Avoid:

- Heavy gradients
- Neon colors
- Overdesigned UI

---

# Tables

Tables should:

- Have proper spacing
- Hover states
- Sticky headers optional
- Clean row separators

---

# Forms

Forms should:

- Have proper spacing
- Clear labels
- Validation states
- Consistent buttons

---

# Empty States

Must include:

- Icon/illustration
- Short message
- CTA button

---

# Responsive Requirements

Support:

- Desktop
- Tablet
- Mobile

Sidebar should collapse properly.
