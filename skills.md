# Project Skills & Guidelines

- Professional
- Spacious
- Minimal
- Responsive
- Production ready

---

# Coding Standards

- Use reusable components
- Use TypeScript everywhere
- Use functional components only
- Avoid duplicated UI code
- Use proper folder separation
- Keep components modular

---

# Styling Rules

- Use Tailwind only
- Use consistent spacing
- Use soft borders and subtle shadows
- Avoid overly colorful UI
- Use modern card/table layouts

---

# Component Rules

Create reusable components for:

- Tables
- Forms
- Status badges
- Modals
- Layout sections

---

# UX Requirements

- Responsive layout
- Smooth interactions
- Hover states
- Empty states
- Loading states
- Toast feedback

---

# Current Scope

ONLY build:

- Templates listing
- Create template
- Edit template
- Delete template
- View template details
- Search/filter UI
- Mock/local CRUD

DO NOT build:

- Authentication
- WhatsApp APIs
- Meta integration
- Cloud deployment
- Production backend

---

# Important

Prioritize:

1. UI quality
2. Component structure
3. UX polish
4. Reusability
5. Clean architecture
